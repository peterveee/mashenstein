A tool started here stops when this desk stops. One that was already running was started by somebody else — it is linked, never stopped. Bookmark /mixer, /levels, /sfx to go straight in, cold or warm. The direct ports still work exactly as they always did, and every tool still runs standalone from its own npm script. A gallery's RUN button does the same npm command by hand would — the screen gallery starts THE GAME first if it is cold, and the asset gallery renders then archives in one press. OPEN appears once one exists on disk.
