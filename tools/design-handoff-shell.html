__NAME__ MASHENSTEIN · character spec

Every frame below is drawn by the game's real painter — drawToon() from src/sprites/toons.js, bundled into this page. Nothing here is a mockup, so what you see is exactly what ships.

How to give notes that can be applied directly:
  • Phrase every change as name: current → proposed, using a name from the Parameters table at the bottom of this page.
  • If you want something no parameter can express, propose it as a new name and say what it should control. That is a useful answer.
  • Check the scope column first. Rows marked ALL 10 HEROES are one shared painter — a change there re-draws the whole cast, so it needs to be worth it.
  • Hard constraints: flat fills and a single outline pass only. No gradients, blurs, shadows or offscreen buffers — the player's hero repaints every frame. The character has to hold up across __SIZE_RANGE__ tall, which is its full range of real presented sizes (phone through desktop).
