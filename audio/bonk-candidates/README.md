# Chase-copter bonk candidates

These are audition renders for the Rhythm Cabinet chase, where the hero jumps
up into the villain from underneath. They are 44.1 kHz, 16-bit mono WAVs.

The current game cue is unchanged. The candidates are ordered in the reel as:

1. `01_rubber_boing.wav` — round, elastic, friendly cartoon spring.
2. `02_coil_spring.wav` — brighter metal coil with a longer twang.
3. `03_cartoon_boink.wav` — strongest comic “bonk → boink” punctuation.
4. `04_vacuum_twang.wav` — breathy low hit and appliance-like rising resonance.
5. `05_arcade_upswing.wav` — stepped 8-bit climb with a crisp arcade edge.
6. `06_heavy_bounce.wav` — lower, weightier impact for a bigger villain reaction.

`00_bonk_reel.wav` places each candidate in a 1-second slot, in that order.

All audio is procedurally generated by `tools/render-bonk-sfx.js`; no candidate
has been wired into gameplay yet.
